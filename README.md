# Tank Battle 坦克大战

一个纯原生 HTML5 Canvas 实现的坦克大战小游戏，无任何依赖，单个 HTML 文件即可运行。

## 玩法

| 按键 | 功能 |
|------|------|
| `W A S D` / 方向键 | 移动 |
| `空格` | 射击 |
| `P` | 暂停 |

- 消灭每一波全部敌方坦克即可进入下一波，敌人会越来越快、越来越多。
- 棕色砖墙可以被炮弹摧毁，灰色钢墙无法击穿。
- 击毁一辆坦克 +100 分，每清空一波额外 +200 分。生命耗尽则游戏结束。

## 运行

直接用浏览器打开 `index.html` 即可，无需安装任何东西。

也可以本地起个静态服务器：

```bash
npx serve .
# 或
python -m http.server 8000
```

## 技术说明

- 纯 JavaScript + Canvas 2D，零依赖、零构建
- 音效由 Web Audio API 实时合成，无外部音频资源
- 敌人 AI：追踪玩家、对齐时瞄准射击、撞墙时尝试拆墙绕路
- 粒子爆炸效果与屏幕震动反馈
